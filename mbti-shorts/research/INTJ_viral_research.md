## 2. INTJで特に共感が集まるネタ（頻出順）

1. **相談されると「原因の分類」と「解決策」を出してしまう** → 相手は共感が欲しかった、と気づくのが遅れる
2. **計画が分単位** — デート/旅行/相談対応まで手帳に書いてある
3. **感情はあるが表に出す必要性を感じない**（楽しんでいるのに顔に出ない）
4. **「もっと気持ちを言葉にして」と言われて困惑**
5. **雑談が苦手**（「今日暑いですね」で会話が終わる）
6. **黒幕/ヴィラン扱いされるが、実は誰より先回りして心配している**（"Mastermind"ミーム）

→ 1・2・3・6を1本の物語に圧縮すると「冷たいと思われた行動が、実は3日前から準備された優しさだった」という**ギャップ回収型**が組める。これがINTJ編の脚本の骨格。

## 3. 縦型ショートの構造上のセオリー（適用済み）

- **0〜2秒に文字フック**（「INTJの友達に失恋相談した結果」）— 最初の2秒で離脱を防ぐ

## 4. 制作手法トレンド（「1コマずつ生成 → mp4化」の確認結果）

確認できた2026年の主流フロー:

1. **静止画（コマ）を1枚ずつ生成** — Nano Banana / Nano Banana Pro・2 でキャラシートを作り、髪色・服装・背景色を固定して全コマの一貫性を保つ
2. **コマを動画化** — (a) Veo 3 / Kling / DomoAI でコマ間を補間して数秒クリップ化、または (b) コマをそのまま **FFmpeg で連番→mp4** に連結（字幕・SEは編集ソフトで後付け）
3. 生成AIは3〜10秒クリップが得意で、長尺化するほど一貫性が崩れるため、**「短いコマ×多数を連結」が実務上の正解**とされている

本リポジトリではこのフローを**完全にコードで再現**している:

- `src/scene.html` … 台本をタイムラインとして持ち、`seek(t)` で任意時刻の1コマを描画（キャラは SVG でベクター描画 → 全コマで一貫性100%）
- `src/render_frames.js` … Playwright(Chromium) で **1コマずつPNG出力**（24fps）
- `src/encode_mp4.js` … 連番PNG → WebCodecs(VP9) → **自作MP4マルチプレクサ** で `.mp4` 化

※ 本実行環境はネットワーク制限で ffmpeg / libx264 を導入できないため、Chromium 内蔵の VP9 エンコーダで MP4 化している。H.264 が必要な場合は `output/INTJ/frames/` の連番PNGに対して README 記載の ffmpeg コマンド1行で再エンコードできる。
