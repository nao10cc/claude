# 台本づくりの成功事例調査 — 冒頭2秒のフックと「コメントしたくなる」構成

調査日: 2026-09-24 / 対象: ショート動画のフック論、スカッと系・2ch系・漫画動画チャンネル、縦型ショートドラマ(ごっこ倶楽部・BUMP)、海外のストーリーアニメ(MSA/Storybooth)、Hook Point

---

## 0. 結論(先に)

1. **冒頭2秒は「結末の一瞬」か「告白の一言」で始める**。説明・タイトル・日常から始めない。今の #2 は「銀行通知 → 巻き戻し → タイトル」で構造は正しいが、**人の顔と感情が0.5秒以内に出ていない**のが弱点。
2. **スカッと系の型は「トラブル → 奮闘 → スカッと」の三幕で、悪役は分かりやすく理不尽、主人公は視聴者の代理**。今の #2 は主人公が最後まで救われず、悪役(詐欺師)も無傷で終わるので「淡々」と感じる。**視聴者が代理で溜飲を下げる瞬間がない。**
3. **詐欺師は"全員が叩いていい悪役"**。スカッと系の最大の批判点(片側の正義で裁く・胸糞)が発生しないので、教養ドラマとスカッとの相性は極めて良い。#2 は**詐欺師が「失敗する」瞬間を見せる**方向に直す。
4. **コメントは「自分の答えを言いたくなる問い」と「体験を語りたくなる余白」で生まれる**。「あなたなら押す?」の二択、「同じSMS来た人」の挙手、あえて残すツッコミどころ、オチを説明せず表情で見せる。
5. **ラストのセリフを冒頭のフリにするループ構成**で2周目に入らせる(視聴完了率100%超がアルゴリズム上の強いシグナル)。

## 1. 冒頭2秒のフック: 成功事例から抽出した型

### 数字で見る「最初の数秒」
- 縦型ショートは**冒頭2秒でほぼ決まる**。Metaの調査では平均スクロール時間は**1.2秒**。
- 30秒動画の標準配分は **フック3秒 / 本編22秒 / CTA 5秒**。
- 伸びなかった動画は「内容」より「冒頭で自分に関係があると認識されなかった」ケースが多く、**フックだけ差し替えて再投稿すると劇的に伸びることがある**。

### 型の一覧(日本の実務系記事 + Hook Point + 海外ストーリーアニメ)
| 型 | 例 | 使いどころ |
|---|---|---|
| **結論先出し(ネタバレ)型** | 「認証コードを打った3分後、口座が空になった」 | 教養ドラマの基本。結果→なぜ? で最後まで見せる |
| **告白(コンフェッション)型** | 「正直に言う。私は詐欺に引っかかった」 | MSA/Storyboothが確立。一人称の弱さの吐露は"友達にしか言わないこと"として耳を傾けさせる |
| **途中から始める(コールドオープン)** | 叫び声・修羅場のど真ん中から | 説明ゼロで感情に入る。ごっこ倶楽部が推奨する「起承転結を捨てる」 |
| **疑問提起型** | 「宅配業者はSMSでURLを送らない。知ってた?」 | 知識系。自分ごと化を狙う |
| **意外性 / パターン割り込み** | 見慣れない絵・音・動き | Hook Pointの「パターン・インタラプト」。視覚フック |
| **ターゲット名指し型** | 「ネット通販を月1回以上使う人、見て」 | 自分ごと化。完視聴率とエンゲージが連鎖 |
| **数字提示型** | 「¥298,000」「3分」「85%」 | 具体数字は止まる。今の #2 も使っている |
| **ビフォー/アフター型** | 「残高 ¥298,000 → ¥0」 | 変化の落差を一枚で見せる |
| **期待スイッチ**(電通PR) | 「スカッとする話」「意外な結末」と先に宣言 | 読後感を約束する。結末で約束を果たせばポジティブなコメントになる |
| **発見スイッチ / 意外性スイッチ**(電通PR) | 「知らなかった」「そうくるか」 | 知識+驚きの組み合わせ |

Hook Point(Brendan Kane)の3分類は **Curiosity(好奇心・開いたループ) / Promise of Value(価値の約束) / Tension(緊張・痛点の劇化)**。教養ドラマは3つを重ねられる: 「口座が空(Tension)」+「なぜ?(Curiosity)」+「見れば防げる(Promise)」。

### 視覚フックと企画フックは両方必要
- 企画フック = 文字・セリフの内容。視覚フック = 0.5秒で目に入る絵(顔のアップ、強い色、動き、SE)。
- **音無し視聴前提**なので、視覚フックと字幕が同時に成立していないと止まらない。
- 冒頭は「顔」。人は顔と目に反射的に止まる。図やUIより先に**驚いた顔・泣き顔・叫び顔**を出す。

## 2. スカッと系・修羅場系・漫画動画の構成

### スカッと系シナリオの定石(YouTube漫画動画のシナリオ講座より)
- 三幕: **トラブル → 奮闘 → スカッと**。各幕をさらに3〜4分割する。
- テンプレ要素: 主人公の情報 / トラブルの種類と原因 / 敵に降りかかる災難 / その理由(因果)。
- 悪役は「理不尽な嫌がらせをする分かりやすい悪」。最後に懲らしめられて視聴者がスカッとする。
- **批判点**: 「片側だけの情報・片側だけの正義で裁いている」「胸糞」「制作動機がトレンドだから」という声が根強い。
  → **詐欺師を悪役にすれば、この批判は原理的に発生しない**(全員が「やられて当然」と思う相手)。教養ドラマ×スカッとは、スカッと系の弱点を消した形になる。

### 2ch修羅場・ゆっくり解説系
- 「状況説明 → 理不尽 → 反撃 → ざまぁ」の型。ショート版は**冒頭で修羅場の結果を先に置き**、本編で経緯を追う。
- 視聴者は「自分ならこうする」「そこで反撃しろ」と**コメントで参加**する。参加の余白(主人公の判断の遅れなど)が意図的に置かれている。

### ヒューマンバグ大学(漫画動画の現トップ)
- テーマ「人間は追い詰められてバグるとどうなるか」。**極端な状況に置かれた人間の反応**を見せる。
- コマ割り漫画 + 声優 + ナレーション。1本4分。2019年開設で同年内に64万人。週5→週3更新。
- 固定キャラ(佐竹など)がシリーズを跨いで登場し、視聴者がキャラを追う。
- 教訓ではなく**人間の闇と因果**で引っ張る。裏社会の話でも「やられた側が報いる」構造。

### テイコウペンギン(170万人超)
- 「社畜(ペンギン)が上司やクレーマーの理不尽に抵抗する」+ 雑学。
- **可愛い見た目 × 毒のある抵抗**のギャップ。理不尽に「言い返す」瞬間が快感の源。
- 雑学を物語の中で使うので、知識が「役に立つ武器」として見える。
  → 教養ドラマの理想形。知識=反撃の武器、という構造は #2 にそのまま使える。

### フェルミ研究所(元祖)
- 「あるある」と「もしも」で共感を集め、漫画動画の様式を確立。2021年終了。後追いが大量発生。

### 海外: MSA / Storybooth(数千万〜億再生)
- 一人称の**告白型**ナレーション。「I was scammed…」のように、当事者が過去を語る。
- 「実際に子どもに起きること」を扱う本物感 + ドラマチックな演出。若年層に強い。
- タイトルは一人称の一文(「私は◯◯した」)。

## 3. 縦型ショートドラマ(ごっこ倶楽部 / BUMP)から

### ごっこ倶楽部(ショートドラマ国内No.1、再生15億回超)
- バズの構造 = **冒頭数秒のつかみ / 展開の転換 / 視聴者コメントによる考察誘導**。
- **5ブロック構造**: フック → 設定 → 展開 → クライマックス → オチ。「起承転結」の"起"を捨てて事件から入る。
- **オチは行動や表情で示し、セリフで説明しない**。説明すると余韻がゼロになり、コメント(考察)も生まれない。
- 結末部(60〜120秒)で伏線回収・感情的共感・オチ。

### BUMP(国内発アプリ、400万DL、SNS切り抜き65億再生)
- 人気ジャンル: **不倫・復讐、女性同士のマウント合戦、下剋上、正体隠し、勧善懲悪**。1話1〜3分。
- 共通項は「見下されていた側が立場を逆転する」。**逆転の瞬間**が切り抜かれて拡散する。
- Z世代の「共感」と「タイパ」志向を捉えたと分析されている。

## 4. コメントを生む仕掛け(TikTok運用の実務知)

TikTokのレコメンドは**コメントとシェアを重く評価**し、視聴完了・リプレイと合わせて「加算」される。

| 仕掛け | 具体 | 効き方 |
|---|---|---|
| **二択・問いかけ** | 「あなたなら押す? 押さない?」「ユウは悪い? 銀行が悪い?」 | 自分の答えを言いたくなる。動画内テロップ+キャプション+固定コメントの3か所に置く |
| **賛否が分かれる余白** | 「そもそも頼んだ荷物が本当にあった」「リンの言い方がきつい」 | 意見が割れる=コメント欄が伸びる。ただし炎上と紙一重なので、割れるのは"判断"に限定し、人格や属性で割らない |
| **あえて残すツッコミどころ** | ユウが2回目も押しそうになる、リンが最後にニヤッとする | 「おい!」と書きたくなる。ごっこ倶楽部の「考察誘導」もこの一種 |
| **体験の挙手** | 「同じSMS来た人👋」「私も来た」 | 詐欺ネタ最大の武器。**ほぼ全員が受信経験がある**ので体験談コメントが自然発生し、コメント欄が"証拠"になる |
| **固定コメントで続きを促す** | 「コメント欄に本物の見分け方まとめてます」 | コメント欄を開かせる=滞在時間 |
| **説明しないオチ** | 表情・行動で終える | 「最後の顔どういう意味?」の考察コメント |
| **視聴者を巻き込む一言** | 「家族に送って」「あなたは何派?」 | シェアとコメントを同時に取る |

## 5. ループ構成(2周目に入らせる)

- YouTubeショートでは**視聴完了率が100%を超える(2回以上見られる)**とおすすめに載りやすくなる。
- **ラストのセリフが冒頭のセリフへの「フリ」になる**構成: 視聴者は動画が終わったことに気づかず2周目に入る。
- 映像でつなぐ高等技: ラストで画面を暗転させ、冒頭も同じ暗転から始める。
- #2 なら、ラスト「…本物は、紙で来た。」→ 冒頭がスマホの通知音「ピロン」で始まると、紙とスマホの対比が輪になる。

## 6. 現行 #2「不在通知SMSを押した3分後」の診断

| 観点 | 現状 | 問題 |
|---|---|---|
| 冒頭2秒 | 銀行通知カード(文字) → 巻き戻し → タイトル | **顔がない**。文字だけで0.5秒の視覚フックが弱い。感情(叫び・青ざめ)が出るのは33秒 |
| 主人公 | ユウが引っかかり、リンに諭され、翌日紙が届く | **救われない・反撃しない**。視聴者の代理が負けたまま終わるので溜飲が下がらない |
| 悪役 | 詐欺師は成功して姿を消す | **無傷**。スカッと系の核である「敵に降りかかる災難」がゼロ |
| 種明かし | 図解19秒 | 正確だが長い。ドラマの緊張が途切れる。ショートでは**図解は8〜10秒に圧縮**し、残りはドラマで見せる |
| コメント誘発 | 「家族に送って」のみ | 問いかけ・二択・挙手・ツッコミどころが無い |
| オチ | 「本物は、紙で来た」(セリフで説明) | 皮肉としては良いが、**セリフで言ってしまっている**。表情と紙だけで見せた方が余韻とコメントが出る |
| ループ | なし | ラストと冒頭がつながっていない |

→ 「淡々」の正体は、**感情の起伏が図解で止まり、最後に誰も勝たない**こと。

## 7. 改稿方針(#2 v2 の骨格案)

### 冒頭2秒の候補(A/Bテスト前提で3案)
- **A. 叫び+数字(コールドオープン)**: 0.0秒 ユウの青ざめた顔のアップ、0.3秒「え、残高…ゼロ?」、0.8秒 通知「¥298,000 送金完了」。1.5秒 巻き戻し「◀◀ 3分前」。
- **B. 告白型**: 黒背景にユウの顔、「正直に言う。俺、不在通知を押した。」→ 通知ピロン。
- **C. 二択型**: 「このSMS、押す? 押さない?」+ 偽SMS画面をドンと出し、2秒後「押した人の3分後がこれ」。

推奨は **A**(顔=視覚フック、数字=企画フック、Tension+Curiosityが同時に立つ)。Cはコメント誘発が最強なので、キャプションと固定コメントで併用。

### 三幕への組み替え(78〜85秒)
1. **トラブル(0〜28秒)**: 現行の流れを圧縮。SMS → 偽サイト → 認証コード入力 → 「処理中」。詐欺師の部屋で「実行」。
2. **奮闘(28〜55秒)**: **ここを新設**。通知を見たリンが0.5秒で「銀行に電話、今」。ユウがパニックで番号を探せない → リンがスマホを奪って公式アプリから緊急停止(ワンタップ)。図解は電話の保留音の間に**8秒だけ**「何が起きていたか」を挿む(認証コード=鍵)。
3. **スカッと(55〜80秒)**: 詐欺師のモニターに「送金失敗 / 口座凍結」の赤文字。詐欺師「は?」→ 画面が「通報済み」に切り替わる(詐欺師の負け顔=ざまぁ)。リビングに「¥298,000 送金取消」の通知。ユウ、床にへたり込む。
4. **オチ(80〜85秒)**: 翌日、ドアの下から紙の不在票。ユウとリンが顔を見合わせる。**セリフなし**。ユウがスマホを裏返して置く。テロップ「認証コードは、鍵。」→ 冒頭の通知音「ピロン」でループ。

※ 実際の送金は取り消せないことも多い。**「すぐ銀行に連絡すれば止まることがある」という事実に基づき、"止められた回"として描く**。キャプションで「止まらないケースも多い。だから押さないのが一番」と補うと誠実さも保てる。

### コメント誘発の配置
- 動画内: 認証コードを入力する直前で1秒だけ止め、テロップ「**ここで止められる人、何%?**」。
- ラストテロップ: 「**同じSMS来た人 👋**」。
- キャプション: 「あなたなら押す?押さない? / 正直に答えて」。
- 固定コメント: 「本物か見分けるチェック3つ↓」(コメント欄に誘導)。
- ツッコミどころ: ユウが最後にまたスマホの通知を見て手を伸ばし、リンに叩かれる(音のみ)。

### 尺と数字
- 60〜90秒に収める(TikTok報酬プログラムの1分超条件を満たしつつ完視聴率を維持)。
- 図解は8〜10秒。字幕は1行12〜14文字以内、2秒以内で切り替え。

## 9. 追記: 「AIの歌に乗せて事件・事故を語るアニメショート」(Suno系)

### 確認できたこと
- **日本でも認知された定着フォーマット**。Yahoo!知恵袋に「TikTokやYouTubeショートでよく出てくる、AIの歌に乗せて過去の事故や事件を歌うやつの作り方」「最近流行っているAIに事件のことを歌わせる動画はどう作っているか」という質問が複数立っており、TikTokには「AIが事件を歌に! 解説・作り方・豆知識」を扱う投稿者もいる。
- 作り方の定番: **ChatGPT等で事件を歌詞化 → Suno でスタイル指定して曲生成 → 歌詞1行ごとに絵を生成し、曲に同期して動画化**(DomoAI / SunoMV 等)。9:16 で書き出してショートへ。
- Suno 側もショート向けに寄せている: 歌詞を自動表示する縦型ショート機能「Hooks」(追加クレジット不要)、テキストメッセージを曲にする「text to song」トレンドで米国DLが週次4倍、iMessage 連携、Apple との提携。2026年9月に v6 系へ移行。
- 「His Story」は YouTube の **"Short Animated Stories"** チャンネルで、月次のコンピレーション(4月/5月/6月版など)を出し、200万人到達を目標に iPhone プレゼント企画や Discord 運営をしている。**歌・AI の使い方や題材の詳細はこの環境からは確認できなかった**(YouTube本体が取得不可)。
- 周辺の注意事例: 実話と称して**架空の事件を AI で量産していた True Crime チャンネル**(人気動画180万再生)が問題視された。YouTube は2025年7月に量産型・非オリジナル(inauthentic)コンテンツの収益化基準を明確化している。

### なぜ伸びるのか(構造)
1. **音楽が視聴維持とリプレイを作る**。曲は途中で切りにくく、サビは何度も聴かれる。ショートのループ再生と相性が良い。
2. **歌詞がナレーションを代替する**。声優・ナレーター不要で「語り」が成立し、字幕(歌詞表示)が視聴維持を支える。音無し視聴でも歌詞が読める。
3. **感情の方向を曲調が決める**。悲劇はバラード、詐欺や因果応報はアップテンポ、と**一発で"どう感じる話か"を伝える**(電通PRの「期待スイッチ」を音で実現)。
4. **量産と横展開**。1事件=1曲=1本。歌詞テンプレ(Aメロ=状況、Bメロ=転機、サビ=結末/教訓)で台本が安定し、シリーズ化しやすい。
5. **顔出し不要・AIアニメ**で faceless 運営ができる。

### このプロジェクトへの取り込み方
- **相性は高い**。今のパイプラインは「WAVを渡せば口パクと尺を合わせる」設計で、曲でも同じ。曲のテンポ(BPM)をタイムラインの基準にすれば、**カット割り・ポーズ切替・テロップの出現を拍に同期**できる(コード描画ならではの正確さ)。
- 歌詞を**カラオケ字幕**として出す描画(今のサビ表示で流用可)、サビで決めゼリフのテロップを重ねる、といった演出は既存資産で可能。
- 声(セリフ)問題の代替解にもなる: **セリフの代わりに歌が語る**ので、VOICEVOX 等を待たずに"音のある物語"が完成する。
- **題材は架空か公的事実に限る**。実在事件を歌う形式は、犠牲者・遺族への配慮、事実誤認、収益化制限のリスクが最も高い領域。教養ドラマ(詐欺・トラブル・心理)なら「架空の被害者の実話"風"」で成立し、リスクを回避できる。
- 制約: この環境からは Suno を呼べない(外部ネットワーク不可)。曲は手元の Suno で作って WAV/MP3 を置いてもらう運用。商用利用は Suno の有料プランが前提。
