# 教養ドラマ #1 台本「不在通知SMSを押した3分後」

- 尺: 約78秒 / 1080×1920 / 24fps / 音声なし(字幕・テロップ) / BGM・SE あり
- 様式: Vyond 風フラット2Dパペット(コード描画リグ `src/rig/rig.js`)
- 登場人物
  - **ユウ**: 20代。ティールのパーカー。ゆるい。宅配偽装SMSを踏む
  - **リン**: 20代。マスタードのセーター。しっかり者の同居人
  - **詐欺師**: フードの影。顔は見えない
- 舞台: 二人のシェアハウスのリビング(夜)。詐欺師の暗い部屋
- 固有名は架空: 宅配「NK EXPRESS」、銀行「みらい銀行」、偽ドメイン `nk-express-jp.top`、正規 `nk-express.co.jp`

## 演出意図

- 冒頭で結末(残高0)を見せて巻き戻す = 「なぜ?」で最後まで見せる
- 前半は台詞少なめのテンポ重視。スマホ画面は全画面化して読める大きさに
- 種明かしは一時停止+白黒で「ドラマ」から「解説」へ切り替わったことを視覚的に示す
- 教訓は説教にならないよう、最後は「本物は紙で来た」の皮肉で締める
- 実在の企業・人物は出さない(架空ブランド、架空ドメイン)
