## 2. ジャンルとシリーズ

**柱: 固定キャストの「日常の落とし穴ドラマ」**(お金・詐欺・心理・法律・仕事)。
「知らないと損する知識」を、視聴者の代理であるキャラが**体験して、反撃して、勝つ**形で見せる。

- 根拠: 日本のアニメ系で育ったチャンネル(ヒューマンバグ大学=追い詰められた人間の因果、テイコウペンギン=理不尽への反撃+雑学、フェルミ研究所=あるある)は全て「限定アニメ+物語+知識/共感」。BUMP の人気ジャンルは復讐・下剋上・勧善懲悪。
- スカッと系の弱点(片側の正義で裁く・胸糞)は、**悪役を詐欺師・悪質業者・理不尽なルール**に限定すれば発生しない。
- 入口枠として **心理系(MBTI)・チャットドラマ**を同じキャストで月数本混ぜ、初速とフォロワーを取る。
- 事故・事件の実話再現は**やらない**(犠牲者のいない教訓事例に限り、シリーズが育ってから)。

### キャスト(シェアハウス)
- ユウ: 引っかかる側。視聴者の代理。
- リン: 知識と行動で反撃する側。決めゼリフ担当。
- 詐欺師/理不尽な相手: 顔のない影。毎回「失敗する」。
- 必要に応じて追加(性格は MBTI 由来で設計し、心理系エピソードにも流用)。

## 3. 台本テンプレ(1本 60〜90秒)

```
0.0–0.8  事後カット(フラッシュフォワード): 結末の"絵"を一瞬。文字より先に顔・状況
0.8–1.5  主人公の顔+一言(「え…?」)。数字を一つ(¥298,000 / 3分 / 85%)
1.5–2.5  巻き戻し「◀◀ 3分前」→ 本編へ(コールドオープン。タイトルカードは置かない)
        ── 第1幕 トラブル(〜25秒): 日常→事件。説明ゼロ、会話とUIで進める
        ── 第2幕 奮闘(〜25秒): 主人公/相棒が動く。図解は8〜10秒に圧縮、行動の"合間"に挿む
        ── 第3幕 スカッと(〜20秒): 悪役側の失敗を必ず画で見せる(モニターの「失敗」、赤文字、負け顔)
        ── オチ(〜5秒): 皮肉。セリフで説明しない。表情と小道具で終える
最後    冒頭の事後カットと同じ構図を"回復した状態"で出す → 冒頭の音/絵にループ
```

### フックの原則
- 冒頭2秒に**顔と感情**。文字カードだけの冒頭は禁止。
- 型は「結論先出し(ネタバレ)」を基本に、A/B で「告白型(正直に言う、俺…)」「二択型(押す?押さない?)」を回す。
- 冒頭カットは**必ず本編で回収**する(無関係な衝撃映像=釣りは規約・信頼の両面で不採用)。
- 暴力・血・死体は使わない。「事後」は散らばった物・落ちたスマホ・赤い数字で表す。

### コメント誘発の配置(毎回)
1. 分岐点で1秒止めて問いかけテロップ(「ここで止められる人、何%?」)。
2. ラストに挙手テロップ(「同じSMS来た人👋」)。
3. キャプションに二択(「あなたなら押す?押さない?」)。
4. 固定コメントに補足情報(見分け方3つ)を置いてコメント欄を開かせる。
5. ツッコミどころを一つ残す(主人公がまた押しそうになる等)。賛否は「判断」で割り、人格・属性で割らない。

### 事実面
- 教訓は事実に基づく(例: 送金は即連絡で止まることがある)。都合の良い結末にした場合はキャプションで補足する。

## 4. 音の方針

- **SE/BGM はコード生成**(`src/lib/sfx.js`)。吹き出し・タップ・通知・巻き戻し・警告・チャイム等の共通SEを「番組の音」として固定し、シリーズ感を作る。
- BGM は場面で切り替える(日常=lo-fi / 緊張=ドローン+アルペジオ / 種明かし=パッド)。決めゼリフはドラムを抜いてシマー。
- **歌バージョン(Suno 形式)を並行して試す**。歌詞=ナレーション代替、サビ=教訓。曲は手元の Suno で作り WAV を渡す。拍にカット・ポーズ・テロップを同期させる(コード描画の強み)。題材は架空ケースに限定。
- 声は別途。導入時は BGM を声区間で自動ダッキング、口パクは音量連動にする。

## 5. 制作パイプライン(確定)

```
scene.html(台本=タイムライン、RIG でキャラ)  audio.html(SE/BGM を秒で配置、または歌 WAV)
        ↓ render_frames.js(1コマずつ PNG)          ↓ render_audio.js(WAV)
        └──────────── tools/build_final.sh ────────────┘
             png2yuv.js(BT.709 変換) → libx264 High@4.0 → AAC(-14 LUFS) → faststart MP4
```
- 1本あたり: レンダリング約12分、エンコード約8分、音30秒。音だけの修正は数秒。
- 品質確認は自動化済み(YUV 数値照合、ラウドネス測定、デコード画の目視、絵コンテ抽出)。
- 新エピソードは `src/episodes/<name>/` に scene.html と audio.html を置くだけ。リグ・SE・ビルドは共通。

## 6. やらないこと(リスク管理)

- 実在の事件・事故・人物・企業の再現。実話を名乗ること。
- 冒頭の無関係な衝撃映像、サムネ詐欺、回収しないフック。
- 血・死体・直接的な暴力(広告制限・年齢制限)。
- 「実話」表記のフィクション(YouTube の量産・非オリジナル基準、TikTok の誤解誘導罰則)。
- 属性で賛否を割る問いかけ(炎上)。

## 7. 計測と改善

- 見る指標: 3秒維持率(フック)、完視聴率とリプレイ率(ループ)、コメント数/再生(問いかけ)、シェア(教訓の実用性)、保存(図解)。
- 運用: 同じ本編で**冒頭2秒だけ差し替えた A/B** を投稿し、フック型を数値で選ぶ(コード描画なら差し替えは数分)。
- 伸びた回は 16 タイプ・別の手口・別のキャラ視点で横展開(パラメータ化)。
